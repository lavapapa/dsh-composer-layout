# Changelog

## 0.1.2 — 2026-08-19

- Anchor the legacy fallback divider to the Composer pane itself, so it cannot drift past the pane when the width reaches its limit.
- Keep the same edge-anchoring rule in the native DSH layout path.

## 0.1.0 — 2026-08-18

- Initial public release of the optional DSH Composer Layout plugin.
- Adds bottom/right placement, per-session layout memory, a resizable right pane, and narrow-window popup positioning.
- Validation target: `deepseek-ai/deepseek-harness` source commit `47f9438` (local source checkout).
